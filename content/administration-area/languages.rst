Languages
=========

OTOBO supports multiple languages.
Each user, Customer Users and Agents, may select their preferred language in their user preferences (refer to the User Guide for more information).

However, the generic translation of specific terms might not fit the domain of information managed with a specific OTOBO instance.
Hence, OTOBO support the customization of the translation.
Existing translations can be customized and new translations can be added.
